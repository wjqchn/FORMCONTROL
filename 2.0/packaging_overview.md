# 2.0 安装包交付说明

## 交付方式
本版本采用与 1.0 相同的安装包流程：

1. 使用 PyInstaller 生成本地服务程序 `FormControl.exe`。
2. 使用 Inno Setup 6 编译安装包 `FormControl_Setup.exe`。

## 成品

- 安装包：`../dist_pkg/FormControl_Setup.exe`
- 打包程序：`build/dist_release/FormControl.exe`
- 安装脚本：`build/FormControl.iss`

## 安装配置

- 版本：2.0.0
- 默认安装目录：`C:\Users\Public\FORMCONTROL`
- 桌面快捷方式：质量文控平台
- 随包文件：`FormControl.exe`、`login.html`、`admin.html`、`表格分类汇总.html`、`图标.ico`
- 数据文件：安装目录下的 `data.sqlite` 与 `auth.sqlite`，卸载时不删除

## 已验证项目

- 安装包文件头为有效 Windows 可执行文件。
- 打包程序健康检查 `/api/health` 返回 200。
- 登录页不再明文展示预置管理员密码。
- 全新部署时登录页直接显示“请设置管理员密码”，固定展示默认管理员用户名 `admin`，仅需填写“设置新密码”和“确认密码”；密码至少 8 位，并须包含大写字母、小写字母、数字、特殊符号四类中的至少三类。中、低强度密码无法完成初始化，高和安全强度可提交。
- 若旧安装或异常中断遗留空的 `auth.sqlite`，登录页首次读取状态会自动补建系统管理员、操作员和查看员，并进入同一设置引导，不会显示无法使用的普通登录表单。
- 中途关闭网页不会保留未完成设置会话；再次打开仍显示设置管理员密码引导。
- 设置成功后才创建正式登录会话，无需输入初始化授权码。
- 修改密码后 `must_change_pw` 清零，并可使用新密码重新登录。
- 最终打包程序验收通过：中强度密码被服务端拒绝；高强度密码可完成首次初始化并返回正式会话；安装包内登录页已包含实时密码强度提示与禁用提交逻辑。
- 验收结束后测试实例已关闭，端口 5178 已释放，临时测试目录已清理。
