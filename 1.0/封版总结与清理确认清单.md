# 表格分类汇总系统封版总结与清理确认清单

生成时间：2026-08-14

## 1. 封版结论

项目现已具备两个可独立交付的安装包版本：

| 版本 | 安装包 | 状态 | 适用范围 |
|---|---|---|---|
| 1.0 | `dist_pkg/FormControl1.0_Setup.exe` | 已封版保留 | 无账户体系的表格/文件分类汇总与备份版本 |
| 2.0 | `dist_pkg/FormControl2.0_Setup.exe` | 已封版保留 | 带账户、角色、权限和首次管理员初始化的正式版本 |

## 2. 1.0 功能总结

- FG 表格与 SG 文件的录入、编辑、分类汇总、版本排序和历史版本标记。
- Excel 模板下载、批量导入、导出与新分类确认树。
- 培训状态管理。
- 本地 SQLite 数据存储、自动备份、备份查询、恢复和过期备份清理。
- 安装包采用 PyInstaller + Inno Setup，安装后在本机运行本地服务。

保留的 1.0 交付物：
- `dist_pkg/FormControl1.0_Setup.exe`
- 根目录的 `表格分类汇总.html`、`server/`、`FormControl.spec`、`图标.ico`
- 现有 1.0 项目总结与备份功能说明。

## 3. 2.0 功能总结

2.0 在 1.0 文控能力基础上增加账户安全与系统管理能力：

- 登录、退出和基于 Bearer Token 的会话控制。
- 用户、角色与权限管理；权限覆盖录入、编辑、导入、导出、备份与管理端访问。
- 账户不会物理删除；失活账户可通过“激活”恢复。
- 首次部署仅展示默认管理员用户名 `admin`，由使用者设置管理员密码；不展示或要求输入预置密码/授权码。
- 密码规则：至少 8 位，且大写、小写、数字、指定特殊符号四类中至少包含三类；中、低强度禁止提交。
- 普通新建或重置账户在首次登录后强制修改密码。
- 账户数据库独立保存，且支持账户备份。
- 正式 UI 采用白色工作台、浅色渐变 Hero、紫蓝主操作、绿色状态与红色危险操作。

保留的 2.0 交付物：
- `dist_pkg/FormControl2.0_Setup.exe`
- `2.0/表格分类汇总.html`、`2.0/login.html`、`2.0/admin.html`、`2.0/server/server.py`
- `2.0/build/FormControl.iss`、`2.0/build/FormControl.spec`、`2.0/build/dist_release/FormControl.exe`
- `2.0/data.sqlite`、`2.0/auth.sqlite`、`2.0/backup_settings.json`、`2.0/图标.ico`
- `2.0/质量文控平台2.0白色全页面展示.png` 与源文件 `2.0/2.0白色全页面展示长图.html`
- `2.0/overview.md`、`2.0/packaging_overview.md`
