# 自动数据库备份功能交付概览

## 已完成

- 正式接入可配置的数据库自动备份、查询、恢复与过期备份清理功能。
- 每次已启用的编辑、删除、导入或恢复操作前，服务端会将当前 `data.sqlite` 创建为独立快照。
- 快照目录默认位于 `D:\文档管理数据库备份\YYYYMMDD_HHMMSS\`，目录内包含 `data.sqlite` 与备份元数据。
- 顶部新增最新备份时间、过期备份占用进度和 75% / 99% 分级提醒。
- 新增备份设置、按日期折叠的备份查询、恢复前二次确认、过期备份清单确认与清理功能。

## 关键行为

- 只有“编辑、删除、导入、恢复前”会按设置创建自动快照；新增条目、打开编辑弹窗、未保存的字段修改和切换历史显示均不会备份。
- 恢复快照前会先按“恢复”开关自动备份当前数据库。
- 过期备份必须先在程序中列出并由用户确认；确认后会移入 Windows 回收站，可恢复。
- 备份设置保存在应用目录的 `backup_settings.json`，恢复历史数据库快照不会覆盖备份设置。

## 验证与交付

- 已通过服务端 Python 语法检查、前端内嵌 JavaScript 语法检查。
- 已在独立临时目录完成运行时验证：设置保存、编辑前快照、恢复前快照、恢复还原、过期标记和确认清理均通过。
- 已重新构建发布服务程序与安装包。
- 最终安装包：`dist_pkg\FormControl_Setup.exe`。

## 使用提示

安装新版后，进入顶部“备份设置”确认路径、触发方式、保留天数和清理提醒阈值。首次发生所选操作前会创建快照。
