# 表格分类汇总系统 — 项目总结

## 一、项目概述

「表格分类汇总系统」是一套面向质量文控场景的桌面应用，用于管理 FG（表格）与 SG（文件）两大类记录的录入、分类汇总、版本追踪、培训状态管理、Excel 批量导入导出与自动数据库备份。

- **安装路径**：`C:\Users\Public\FORMCONTROL`
- **最终安装包**：`dist_pkg\FormControl_Setup.exe`（15.11 MiB，2026-08-13 11:37）

## 二、技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | 原生 HTML/CSS/JavaScript（单文件，无框架） | `表格分类汇总.html`（136 KB），含全部 UI 与业务逻辑 |
| 后端 | Python 标准库 `http.server` + `sqlite3` | `server/server.py`（22 KB），仅监听 `127.0.0.1` |
| 数据库 | SQLite | `data.sqlite`，records 表存 JSON 行，settings 表存键值 |
| 打包 | PyInstaller → Inno Setup 6.7.3 | exe 托管本地服务，安装包释放 exe + HTML + 图标到安装目录 |
| 启动 | 桌面快捷方式 → `FormControl.exe` | exe 启动本地 HTTP 服务并自动打开系统浏览器 |

### 架构演进

1. **初期**：纯 HTML + 浏览器 IndexedDB（无需后端，但数据隔离在浏览器）
2. **当前**：捆绑本地 Python 服务 + SQLite（数据落盘到安装目录，不依赖浏览器存储）

## 三、核心功能模块

### 1. 录入与编辑

- **FG（表格）字段**：名称、编号、大类、亚类、版本号、生效日期、作废日期、作者、部门、关联 SOP 编号、关联生物城表格编号、培训状态
- **SG（文件）字段**：名称、编号、大类、亚类、生效日期、作废日期、版本号、作者、部门、关联表格编号、关联生物城 SOP 编号、培训状态
- 录入区三列网格布局，编辑弹窗复用同一表单面板（严格等宽两列）
- 名称与编号同行并列，日期控件点击即弹日历选择器

### 2. 分类汇总展示

- 按「大类 → 亚类」树状分组，支持折叠/展开
- FG 汇总无序号列，SG 汇总保留序号列
- **版本排序**：同一编号下最新版本在上，历史版本依次在下
- **历史标记**：仅旧版本（存在更高版本时）在版本号后显示红色「历史」标签
- 支持按编号排序与按名称排序两种模式
- 行垂直居中，列间分隔线，编号分色（FG 蓝、SG 绿）
- 未配置大类/亚类名称时显示笔形编辑按钮（✎），可就地命名

### 3. 培训状态管理

- SG 文件行培训列使用 iOS 风格胶囊开关（已培训/待培训）
- 胶囊 78×26px，纯白圆点无杂边，文字在圆点对侧

### 4. Excel 批量导入导出

- 导入支持 FG/SG 混合，自动检测重复并区分新增/覆盖/跳过
- **分类确认树**：导入时若检测到新大类/亚类，弹出完整树状确认框
  - 完整展示「大类 → 亚类」层级
  - 新增节点红色突出 + 「将新增」标签
  - 既有节点灰色「已有」标签
  - 大类可折叠/展开（圆角加减号控件）
- 导入完成后立即从服务端重新读取记录，汇总即时刷新

### 5. 自动数据库备份

- **默认路径**：`D:\文档管理数据库备份\YYYYMMDD_HHMMSS\`
- **快照结构**：`data.sqlite` + `backup.json`（操作类型、时间、大小）
- **触发时机**（可独立开关）：
  - 编辑条目前
  - 删除条目前
  - 导入数据前
  - 恢复备份快照前
- 明确不触发：新增条目、打开编辑弹窗、未保存的修改
- **备份查询**：按日期树状分组，默认展开当天，支持恢复至指定快照（二次确认）
- **过期清理**：按阈值（默认 1 GB）计算占用百分比
  - < 75%：纯绿色
  - 75%–98%：黄红预警
  - ≥ 99%：深红，提示进入清理
  - 清理时移入 Windows 回收站，非永久删除

### 6. 数据库恢复

- 支持从备份 JSON 导入恢复（页面内确认弹窗，非原生 confirm）
- 恢复前自动创建快照

## 四、UI 设计要点

- **Hero 渐变**：多层叠加渐变（青绿→蓝→紫→粉→暖金）+ radial-gradient 光斑
- **字体**：全局 Rockwell + 微软雅黑/苹方 fallback；数字列 DIN 风格 + `tabular-nums`
- **弹窗按钮统一**：主操作紫蓝渐变、次操作白底灰字、危险操作红色渐变，全部静态无 hover 变化
- **顶部状态**：透明叠加于 Hero，无白底卡片，显示数据库连接与最新备份时间
- **备份设置**：四项触发器使用 55×18 无文字胶囊开关，外侧标签为编辑/删除/导入/恢复

## 七、API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/records` | 获取全部记录 |
| POST | `/api/records` | 覆盖写入全部记录 |
| GET | `/api/settings` | 读取设置 |
| POST | `/api/settings` | 保存设置 |
| GET | `/api/backups/status` | 备份状态（最新时间、过期占用） |
| GET | `/api/backups` | 备份列表 |
| POST | `/api/backups/settings` | 保存备份设置 |
